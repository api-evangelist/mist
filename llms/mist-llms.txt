# Mist (Juniper Mist Cloud API)

> AI-driven cloud platform for wireless, wired, and WAN networking. The Juniper Mist Cloud API is a RESTful HTTPS/JSON API (OpenAPI 3.1, 748 paths / 1050 operations) organized around an Org -> Site -> Device hierarchy. Token authentication (Basic Auth deprecated Sept 2026); 5000 requests/hour quota; org/site webhooks plus WebSocket streaming; 12 regional hosts.

## API

- [Juniper Mist Cloud API docs](https://www.juniper.net/documentation/us/en/software/mist/automation-integration/): Automation & integration guide.
- [API reference](https://www.juniper.net/documentation/us/en/software/mist/api/http/): Interactive endpoint reference.
- [Getting started](https://www.mist.com/documentation/category/getting-started-api/): First API calls and token setup.
- Base URL: https://api.mist.com/api/v1 (substitute "api" for "manage" in your portal host for other regions).
